Escape during a mission opens the in-game options menu. Its **Game Controls**
button opens a second dialog for Keyboard, Sound, and Display settings while
the game keeps running.

## Changing the display

**Display** opens the same display options dialog the classic main menu's
Options screen uses, and a chosen resolution is tried the same way: the game
switches to it, waits for the player to confirm, and reverts if they do not.
Trying a mode during a mission redraws the tactical map behind the trial
instead of the main menu's background art, since a running game keeps no menu
art to redraw. The confirmation prompt that used to precede the trial itself
is gone; choosing a resolution tries it immediately.

## Quitting to the desktop

The single-player in-game menu's **Quit Game** button asks the player to
confirm before it exits, then closes the game outright and skips the main
menu, unlike **Abort Mission**, which ends the mission and returns to it.
