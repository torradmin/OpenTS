The in-game options menu's Game Controls dialog gains a Display button, so a running mission can change resolution the same way the main menu already could, instead of requiring a return to the main menu first. The single-player in-game menu also gains a Quit Game button that confirms, then exits straight to the desktop rather than back to the main menu.

Trying a resolution change no longer shows a confirmation prompt before the trial itself; the game switches to the chosen mode immediately and still reverts it if the player does not confirm in time.
